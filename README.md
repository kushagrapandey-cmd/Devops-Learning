# Systems and Automation Reference

Bash fundamentals and an organized reference workspace for systems administration and automation.

## Executable example

[`scripts/bash/my_first_bashScript.sh`](scripts/bash/my_first_bashScript.sh) demonstrates:

- System information using `whoami`, `hostname`, `date` and `uptime`.
- Bash variables, substring extraction, prefix/suffix removal and case conversion.
- Script name, positional arguments and argument counts.

Run on Linux or WSL with Bash:

```bash
bash scripts/bash/my_first_bashScript.sh example
```

Read the script before running it. It prints system information and string examples, with a three-second pause; it does not provision infrastructure.
